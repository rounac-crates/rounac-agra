# Rounac A-GRA
A-GRA bindings used by the [rounac][1] crate.

# Contents
The bulk of the source content is generated by [xsd-generator][2], whose
`lib.rs` becomes the mod file with all other files placed into that module's
folder; the mod name is based on the input schema version. Each module then
gets a dedicated feature but only the latest schema version is part of the
default features.


[1]: https://github.com/rounac-crates/rounac
[2]: https://github.com/rounac-crates/xsd-generator
